¿Qué hace que un videojuego sea superventas?

Este proyecto utiliza un modelo de aprendizaje automático para estimar si un videojuego alcanzará al menos un millón de unidades vendidas. Las gráficas comparan la proporción de superventas dentro de cada género y plataforma; no representan una garantía de éxito ni una relación causal.

Cómo funciona el modelo

Se utiliza una Regresión logística dentro de un pipeline, que prepara los datos y calcula la probabilidad estimada de superventas.

  • Año (Year): se completan valores ausentes con la mediana y se estandariza.
  • Plataforma (Platform), género (Genre) y editora (Publisher): se completan ausencias con la categoría más frecuente y se convierten en variables numéricas.
  • Las categorías con menos de 30 ejemplos se agrupan como poco frecuentes; categorías nuevas se gestionan sin detener la predicción.
  • La etiqueta «superventas» significa ventas globales de al menos 1 millón.

Datos y evaluación

  • El conjunto se divide en 80 % para entrenamiento y 20 % para prueba, manteniendo la proporción entre clases.
  • La ponderación de clases ayuda a que el modelo preste atención a la clase minoritaria.
  • AUC en prueba: 0.808. Mide la capacidad de ordenar un superventas por encima de un juego que no lo es (0,5 equivale al azar; 1,0 es una separación perfecta).
  • Recall de superventas: 72.6%; identifica esta proporción de los superventas reales.
  • Precisión de superventas: 27.5%; de los juegos marcados, esta proporción sí alcanza el umbral.
  • F1 de superventas: 39.9%; combina precisión y recall en una sola medida.

Evaluación calculada con una partición de prueba reproducible del archivo vgsales.csv.

Proporción de superventas

Se considera superventas un juego con ventas globales iguales o superiores a un millón. La clase está desbalanceada: solo una parte de los títulos alcanza ese nivel.

Correlación de ventas regionales

Las ventas regionales están relacionadas con las ventas globales. No se usan como variables predictoras porque contienen información que solo se conoce después de vender el juego (fuga de información).

Matriz de confusión

Compara la clase real con la predicción. La diagonal son aciertos; las celdas fuera de ella son errores.

Curva ROC

Resume el equilibrio entre detectar superventas y producir falsas alarmas para distintos umbrales. Un AUC más próximo a 1 indica mejor capacidad de discriminación.

Influencia de las variables

Se muestran los diez coeficientes más positivos y los diez más negativos. En la regresión logística, el signo indica la dirección de la asociación aprendida, no una causalidad.

Las tasas describen este conjunto de datos histórico y no deben interpretarse como una predicción causal ni como una garantía de ventas futuras.
